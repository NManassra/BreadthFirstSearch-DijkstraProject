# Shortest-Path City Navigator

> Supporting — Algorithms · Birzeit University Computer Engineering portfolio

A C project that compares BFS and Dijkstra-based routing between cities, displays the chosen path, and writes results to a file.

## What this demonstrates

- C
- graphs
- BFS
- Dijkstra's algorithm
- shortest paths
- file I/O

## Repository contents

The implementation is in `P4_1212359_NouraManassra_Section5.c`; city input and saved results are included.

## Getting started

Compile with GCC and run it beside `cities.txt`.
